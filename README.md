# 航空公司运行知识库
面向航空公司运行领域的个人资料库，用于学习与备考。目前已完成 **航空气象** 模块，后续将持续扩充其他运行相关领域。

在线访问：[https://31nm.github.io/aviation-knowledge/](https://31nm.github.io/aviation-knowledge/)

## 当前内容（航空气象）



| 模块        | 内容                                                                                    |
| --------- | ------------------------------------------------------------------------------------- |
| 基础大气理论    | 大气成分与分层、标准大气、气压场、温度层结与稳定度、湿度、风与大气环流、气团与锋                                              |
| 天气现象与成因   | 云的分类、降水、雾与能见度、雷暴、锋面天气、台风、积冰、湍流颠簸、风切变、沙尘与火山灰                                           |
| 观测与预报产品   | 观测体系、METAR/SPECI、TAF、RMK 注释组（8 组速查）、天气图与高空图、卫星云图、天气雷达、SIGMET/AIRMET/PIREP、ATIS/VOLMET |
| 危险天气与飞行影响 | 雷暴危害、低空风切变、低能见度运行、积冰、颠簸、台风影响、火山灰与沙尘、放行决策要点                                            |
| 法规标准      | 气象服务与法规体系、CCAR 相关条款、ICAO 附件、报文规范与样例                                                   |
| 备考自测      | 35 道自测题，按模块分类，含 RMK 专项                                                                |

## 特性



* 单文件 HTML，无需安装，双击即可离线使用

* 全文搜索、明暗主题切换、移动端适配

* 内置 METAR / TAF / RMK 报文解码器

* 11 幅内联示意图

* 侧栏导航分组折叠、滚动自动高亮
