## 特性

* 单文件 HTML，无需安装，双击即可离线使用；页内 hash 路由，总览 / 详情 / 自测三视图切换
* 全文搜索：输入即出结果列表，点击跳转对应知识点详情并高亮命中
* 明暗主题切换、移动端适配、侧栏分组导航
* 内置 METAR / TAF / RMK 报文解码器，词素表 77 条（含天气现象、云量云状、风温压、SIGMET 等缩写释义）
* 内联 SVG 示意图（标注示意）
* 学习路径引导与高频考点速览
